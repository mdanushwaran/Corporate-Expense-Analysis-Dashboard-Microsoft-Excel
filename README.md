**📊 Corporate Expense Analysis Dashboard | Microsoft Excel**
**📌 Project Overview**

Developed a Corporate Expense Analysis Dashboard in Microsoft Excel to analyze organizational expenses across multiple departments, 
vendors, payment methods, and expense categories. The dashboard transforms raw expense data into meaningful business insights 
using Excel's advanced analytical features.

This project demonstrates end-to-end data analysis, from raw data preparation to interactive dashboard reporting.

**🎯 Business Problem**

Organizations generate thousands of expense records across departments. Without proper analysis, it becomes difficult to monitor:

Department-wise spending
Budget allocation and remaining budget
Expense approval status
Vendor spending
Payment methods
Category-wise expenses
Overall financial performance

The objective of this project is to provide management with an interactive dashboard for monitoring expenses and supporting data-driven financial decisions.

**🧹 Step 1 – Data Cleaning**

Performed comprehensive data cleaning to improve data quality.

Activities Performed
Removed duplicate records
Checked missing values
Corrected inconsistent department names
Standardized payment methods
Standardized approval values (Yes / No)
Removed unnecessary spaces using TRIM
Applied Proper Case formatting
Converted Amount, Budget Allocated, and Budget Remaining into numeric format
Applied Indian Currency formatting
Converted dataset into an Excel Table

**✅ Step 2 – Data Validation**

Implemented validation techniques to maintain data integrity.

Validation Rules
Dropdown list for Department
Dropdown list for Category
Dropdown list for Payment Method
Dropdown list for Approval Status
Restricted numeric values for Amount
Restricted duplicate Expense IDs

**📊 Step 3 – Data Analysis**

Analyzed expenses using Pivot Tables.

Analysis Performed

Vendor-wise Expense

Approved vs Pending Expenses

Budget Remaining Analysis
Average Expense by Department
Expense Count by Department
